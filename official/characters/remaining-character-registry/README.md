# Registry nhân vật còn lại — Đã di trú

File `remaining-character-registry.md` cũ từng gom nhiều nhân vật placeholder vào cùng một Markdown. Cấu trúc đó **đã bị loại bỏ** theo quy tắc một nhân vật = một file.

Tất cả identity có tên trong baseline cũ đã được chuyển sang profile riêng trong các thư mục:

- `core-profiles/`
- `tv-supporting-profiles/`
- `season3-profiles/`
- `rttt-boane-profiles/`
- `shorts-profiles/`
- `cinderella-gray-profiles/`
- `staff-human-profiles/`

Không dùng file này để lưu nhiều profile mới. Nhân vật mới phát hiện phải được tạo một Markdown riêng và thêm link vào `../INDEX.md`.

Nếu source đã được kiểm tra nhưng không công bố một trường, ghi `UNSPECIFIED`. Sau pass chuẩn hóa, hồ sơ cạn dữ kiện gắn `SOURCE-LIMITED`; field riêng lẻ mà nguồn không công bố giữ `UNSPECIFIED`.
