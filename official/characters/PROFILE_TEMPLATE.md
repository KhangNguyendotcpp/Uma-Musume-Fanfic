# Template Profile Nhân vật — Chuẩn chi tiết

Mỗi nhân vật phải có **một file Markdown riêng**. Mức chi tiết mục tiêu là đủ để writer có thể viết đúng nhân vật mà không phải mở wiki cho mọi cảnh. `Gentildonna` là profile mẫu high-detail hiện tại.

```markdown
# Tên nhân vật

> Cảnh báo continuity/source nếu cần.

## 1. Định danh
- Tên English / Nhật / Romaji
- Biệt danh / danh hiệu / tagline
- Loại nhân vật
- Continuity nguồn

## 2. Hồ sơ cơ bản
- Sinh nhật
- Age nếu source nói rõ
- School division / year / class
- Dorm / roommate
- Chiều cao / cân nặng-note / số đo / cỡ giày
- First-person pronoun
- Cách gọi Trainer / senior / junior nếu có
- Seiyuu
- Solo song nếu có

## 3. Tính cách
- Core personality
- Public vs private presentation
- Competitive temperament
- Cách phản ứng với thắng/thua/training nếu source có

## 4. Đời thường / sở thích / thói quen
- Likes / dislikes
- Hobbies
- Ear habits / tail habits
- Family notes
- Personal rules
- Phone/background / before-race routine / secrets / food nếu source có

## 5. Ngoại hình
- Hair / eyes / ears / tail
- Accessories
- Uniform/race outfit/casual tendencies

## 6. Racing / vai trò narrative
- Surface/distance/style nếu source nói
- Signature race behavior
- Strengths/weaknesses được narrative chứng minh
- Major race anchors

## 7. Quan hệ
- Target
- Loại quan hệ
- Source continuity
- Cách xưng hô / dynamic / shared events nếu có

## 8. Animation / media appearances
- Series / episode / movie / shorts
- Named/mentioned/background status

## 9. Trivia / lưu ý cho fanfic
- Fact lạ hữu ích
- Common OOC traps
- Phân biệt hard canon với comedy gag / community inference

## 10. Nguồn đã khai thác
- URL chính thức
- URL wiki/community navigation
- Drive file/folder hoặc episode/chapter

## 11. Trạng thái nghiên cứu
`FOUND / NORMALIZED` hoặc `FOUND / NORMALIZED / HIGH-DETAIL`
```

### Quy tắc thiếu dữ liệu
- Source đã kiểm tra nhưng không nói: `UNSPECIFIED`.
- Source mâu thuẫn: `CONFLICTING`, ghi từng continuity.
- Chỉ dùng `NOT_YET_NORMALIZED` khi **chưa thực sự research** trường đó.
- Không suy birth year/tuổi từ ngựa thật.
- Không biến nhận diện ngựa thật của community thành official identity.
