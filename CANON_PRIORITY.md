# Canon Priority

When sources conflict, use this order:

1. **Latest explicit author decision** in conversation.
2. **LOCKED fanfic canon** in this repository.
3. **Events already established in written fanfic prose**.
4. **`KhangNguyendotcpp/original-universe-canon`** for the original identity/history/personality/family/metaphysics of Haise, Takiyama and Equinox.
5. **ADOPTED official Uma Musume facts** recorded in this repository.
6. **Official Uma Musume facts not yet adopted**, always tagged by continuity/source.
7. **Real-horse/JRA reference material**.
8. **Assistant inference, reconstruction or DRAFT proposal**.

A lower-priority source never silently overwrites a higher-priority one. If Cygames material says A while this fanfic has deliberately LOCKED B, B remains true in this continuity until the author explicitly changes it.

## Official canon is not one continuity

Never flatten TV S1/S2/S3, game, RTTT, Beginning of a New Era, Cinderella Gray, Umayuru and Umayon into one unquestioned timeline. Preserve source tags first; adoption into the fanfic happens separately.
